Capability class
UPE v5.6.0

Meta-harness / control language

Its real capability is making tasks, authority, evidence, tools, models, actions and acceptance explicit across surfaces. It can improve a human-guided ChatGPT/Codex workflow immediately, but it cannot itself persist a process or enforce a retry budget.

W‑200 package

Executable architecture contract

It resolves the major design questions: trusted-host ownership, Windows-native v0, state/event ordering, action reconciliation, checkpoints, verifier limits and surface boundaries. It is ready to guide implementation.

Planned v5.6.1

Minimal long-running harness

The intended delta is not “better prompting.” It is host-enforced lifecycle, persistence, isolation, deterministic validation and recovery around a real Codex adapter. Until the C‑series passes, this remains a target architecture.

Adaptation quality

Where the design improves on literal copying

The accepted specification generally adapts article patterns to Denys’s authorization and Windows constraints instead of cloning provider-specific mechanisms.

Git commit per session → host checkpoint

Anthropic uses descriptive Git commits as recovery points. UPE separates routine recoverability from repository publication: patch/diff snapshots are automatic; commits remain explicit, approval-gated milestones.

Progress file → canonical state + audit mirror

A Markdown/text progress file is easy to corrupt or reinterpret. UPE specifies SQLite lifecycle state, a transactional outbox and deduplicated JSONL mirror, with conversation history treated only as context.

LLM judge → deterministic-first verifier

The evaluator cannot waive a failing test, add criteria, mutate artifacts or authorize actions. Semantic judgment is limited to criteria without a deterministic oracle and must return insufficient evidence rather than guess.

Immediate multi-agent scale → single-agent proof first

The v0 scope defers scheduler, dynamic routing and multi-agent execution until lifecycle, recovery, idempotency and fake-adapter tests pass. This is slower to impress and much easier to falsify.
